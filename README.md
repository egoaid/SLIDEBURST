# SLIDEBURST v0.1.0 (build 20260917a)

一瞬の横移動で、静止した被写体を立体的に動いて見せるカメラ — その**技術検証用プロトタイプ**です。

Nimslo のような多眼フィルムカメラを、iPhone の1眼で置き換えられるか。
鍵になるのは「撮影時間を極端に短くすること」です。被写体が動き出す前に、
カメラ位置だけが変わった複数フレームを取り切れるかどうかを、実機で数値として確かめます。

このバージョンで確認できること:

- 0.05 / 0.10 / 0.15 / 0.20 / 0.30 秒のバースト撮影で **実際に何枚取れるか**
- 実測フレームレート、フレーム間隔の平均・最短・最長・ばらつき
- 記録解像度、センサー出力解像度、トラックの設定値、取りこぼし枚数、シャッター遅延
- 取得した全フレームの一覧表示と、1コマずつの視点確認
- 13 / 24 コマなどに間引いた **往復再生（1→N→2）** のプレビュー
- インカメラ／アウトカメラの切り替え

画像加工・位置合わせ・3D処理・GIF / APNG / MP4 書き出しは、この段階では未実装です。

## GitHub Pages で公開する

1. 新しいリポジトリを作り、このフォルダの中身をそのまま置く（`index.html` がルートに来るように）
2. Settings → Pages → Source を `Deploy from a branch` にして、`main` / `root` を選ぶ
3. 発行された `https://<user>.github.io/<repo>/` を iPhone で開く

ビルド不要の静的サイトです。パスはすべて相対指定なので、サブディレクトリ配信でも動きます。

> カメラは **HTTPS でのみ**動きます。`file://` やローカルの `http://` で開くと起動しません。
> 手元で試す場合は `npx serve` などではなく、HTTPS が張れる方法か、`localhost` を使ってください。

## 実機での試し方

1. 被写体（人でも物でもよい）に正対し、**カメラを起動**
2. 撮影時間を選ぶ。まず 0.15s から始めるのがおすすめ
3. シャッターを押すのと同時に、**手首を回さず**、カメラ本体そのものを水平に横へ滑らせる
   - 移動量の目安は 5〜15cm。被写体が近いほど少なく
   - 画面中央の破線が水平の目安です
4. 結果画面で、コマ送りしながら各フレームの視点がずれているか確認する
5. 往復再生で「奥行きだけが左右に揺れる」感じが出るかを見る
6. 計測結果を読み、撮影時間・記録解像度を変えて再試行する

**判断の目安**: 実測 60fps 付近が出ていれば、0.20s で 12〜13 コマ前後が取れます。
30fps しか出ない端末・設定では、13 コマ取るのに 0.4s 以上かかり、被写体の動きが混ざり始めます。
その場合は「記録解像度」を下げ、「ストリーム設定」をフレームレート優先にしてください。

## 技術的な選択

| 項目 | 採用したもの | 理由 |
| --- | --- | --- |
| 映像取得 | `getUserMedia` + `<video playsinline>` | iOS Safari / Chrome / Edge すべてで動く唯一の入口 |
| フレーム取得 | `video.requestVideoFrameCallback()` | **実際にデコードされたフレーム**ごとに呼ばれ、`mediaTime` と `presentedFrames` が取れる。取りこぼし計測もできる |
| 代替経路 | `requestAnimationFrame` | rVFC 非対応環境向け。画面描画周期に依存するため参考値扱い |
| 保存 | 事前確保した `<canvas>` プールへ `drawImage` | 撮影中の `canvas` 生成やメモリ確保はフレーム落ちの原因になる |
| 外部ライブラリ | なし | 0.1 秒単位の挙動を測るのに、余計な層を挟みたくないため |

`MediaRecorder` を使わないのは、コンテナ化・可変フレームレート・キーフレーム待ちが入り、
「どの瞬間の何枚目か」を正確に扱えなくなるためです。`ImageCapture` は iOS が未対応です。

記録解像度の初期値を 50% にしているのは、`drawImage` のコピー負荷がフレーム落ちに直結するためです。
まず 50% で挙動を確かめ、余裕があれば上げてください。

## ファイル構成

```
index.html
css/
  base.css      変数・リセット・タイポグラフィ
  layout.css    画面骨格・ヘッダー・フッター
  camera.css    プレビュー・撮影ガイド・シャッター
  controls.css  パネル・チップ・ボタン・スライダー
  result.css    ループ再生ビューとフレーム一覧
  metrics.css   計測値テーブル
js/
  config.js     アプリ定数（撮影時間・コマ数・制約プリセット）
  utils.js      小さな共通処理（間引き・往復列・環境判定）
  camera.js     getUserMedia とストリーム管理
  capture.js    バースト撮影の中核とフレームプール
  frames.js     結果の保持・間引き・サムネイル生成
  playback.js   往復ループ再生プレイヤー
  metrics.js    計測値の算出・表示・書き出し
  ui.js         DOM の組み立てと表示切り替え
  main.js       全体の進行役
```

機能ごとに 1 ファイル。CSS と JS は互いを参照せず、`main.js` だけが全体を束ねます。
